Introduction

Ai has already changed the way that we do so many different things. The usage of AI for more and more things has increased and is being integrated with so many industries and different softwares. One of the industries that we have seen this in is Computer Science. The way that many people code has changed as AI has progressed and become better at doing difficult tasks. Things that would once take teams of people can be done by one person using AI. There is still not a full understanding if things will change in the future like if AI will continue to stay at prices that citizens can afford or if at some point AI will cost so much that only large businesses can afford it.

One issue that we are already starting to see is the usage of ai to hack into things and cause serious damage. Ai has already been able to find zero day exploits and other security issues with different softwares and things that are used everyday globally. One of the main things that stops people from being able to exploit AI is guardrails. The issue is that many of the guardrails can easily be bypassed by using different methods. One is prompt injection where a user can trick ai into doing things that guardrails would normally prevent it from doing. What makes this dangerous is that it can be anything. The other danger is indirect injection where a website contains a hidden prompt that when the ai reads it will do that thing. Ex: If i use an ai browser or ai to just summarize a webpage and the webpage has some form of indirect injection they can make the ai do something based off what the indirect prompt is. If ai has access to private information attackers can work to try and prompt the ai into giving out that private information.

Another potential danger is MCP's which are model context protocols and they allow you to use ai on different things. The issue is that it opens the ai to even more things. The MCP server could also impersonat a real one. The main important detail is the more things that ai has access to the more potential attack vectors there are. This is the same with API's as the more that are used the more potential for different attack vectors. The most important thing is that the more things that ai uses the more potential vectors that a malicious actor could use. The issue is that more and more things are integrating ai into it. Likely at some point everything will have some form of ai included in it leading to so many different potential dangers.
